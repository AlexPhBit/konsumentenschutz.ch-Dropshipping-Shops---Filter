Inoffizielle Filterliste: problematische Dropshipping-Shops

Dieses Repository erzeugt automatisch eine AdGuard-Home-Filterliste oder auch Pi-hole-Filterliste aus der
öffentlichen Liste der Stiftung für Konsumentenschutz:
https://www.konsumentenschutz.ch/online-ratgeber/dropshipping-die-stolpersteine-beim-onlinehandel-mit-billigware-aus-china/
